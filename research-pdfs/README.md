# Research PDFs

Publication records are defined in `../js/publications.js`. Each record points to one PDF in this folder through its `pdf` field.

To add or replace a manuscript:

1. Put the PDF in this folder.
2. Update the matching `pdf` path in `../js/publications.js`.
3. Use `highlight: true` for papers that should appear in the top group.
4. Use `defaultShow: true` on one record to load it in the reader by default.

Role labels are written manually in `../js/publications.js`. Use `Co-first author` when the paper states that the authors contributed equally.
